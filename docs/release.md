# النشر

نشر نسخة جديدة يعني **رفع لفرع `main`**، وكل شي بعدها يصير لحاله: الموقع، وخادم الغرف، وتطبيق أندرويد. الإعداد الأول (ربط Cloudflare ومفتاح التوقيع) في [SETUP.md](../SETUP.md).

## الخطوات

1. **اختبر** (انظر [testing.md](testing.md)): التجربة السريعة للي تغيّر، و`tfull` إذا يمس الأونلاين، واللقطات.
2. **حدّث الكتالوج** إذا تغيّرت ألعاب أو قوانين: `node tools/gen-games-doc.js`.
3. **غيّر رقم النسخة:**
   ```sh
   sh tools/bump.sh
   ```
   - يكتب رقم جديد (وقت الحين بالثواني) مكان كل `?v=` في `public/index.html`. كذا الجوالات والمتصفحات تحمّل الملفات الجديدة بدل المحفوظة.
   - ويكتب نفس الرقم في `public/version.json` مع رابط صفحة التطبيق. التطبيق يقرا هالملف ويطلّع «فيه تحديث للتطبيق» إذا الرقم أكبر من رقمه.
   - **بدونه** الأجهزة تبقى على الملفات القديمة، وما يطلع تنبيه التحديث.
4. **ارفع لـ `main`.**

## وش يصير بعد الرفع

### الموقع وخادم الغرف (Cloudflare)

- **مين ينشر:** المستودع مربوط بـ Cloudflare Workers، وكل رفع لـ `main` ينشر لحاله:
  - ملفات `public/` كموقع ثابت (`assets` في `wrangler.jsonc`)؛
  - و`worker/index.js` كخادم الغرف، مع Durable Object اسمه `Room` لكل غرفة.
- **التجربة على جهازك:** `npx wrangler dev`.
- **تغيير يمس الغرف:** إذا غيّرت بروتوكول الغرف بشكل يكسر التوافق، ارفع `NETV` في `public/js/net.js`. والخادم **ما يقبل** طلب ما فيه `?c=1` (فتح غرفة جديدة) ولا `?j=1` (دخول غرفة مفتوحة، أو الرجوع لها بعد انقطاع أو تحديث صفحة): يرد «noroom». مسار التوافق مع النسخ القديمة انحذف بقرار صاحب المشروع (2026-11-18)، لأن التطبيق للحين تحت التطوير وما أحد عنده نسخة قديمة.
- **حد تخمين الرمز:** الجهة اللي تفشل 20 مرة في الدخول (رمز ما فتحه أحد) خلال 10 دقايق، يرد عليها الخادم «noroom» على أي رمز لين تخلص المدة. العدّاد في كائن واحد مشترك (`gate`) في الذاكرة بس. التفاصيل في [review-guards.md](review-guards.md).
- **الدومين الخاص:** يحتاج سطر في `WSROOM.available` (التفاصيل في [SETUP.md](../SETUP.md)).

### GitHub Pages

- إذا GitHub Pages مفعّل للمستودع، ينشر نسخة ثابتة من الموقع مع كل رفع.
- فيها يشتغل «على نفس الجهاز» و«ضد البوت».
- **أما الأونلاين** فيحتاج رابط Cloudflare (`workers.dev`)، لأن الغرف ما تنفتح إلا من عنوان يقبله `WSROOM.available`.

### تطبيق أندرويد (GitHub Actions)

- **متى يشتغل:** الـ workflow `.github/workflows/android.yml` («Android app») يشتغل مع كل رفع لـ `main` يغيّر `public/` أو `app/` أو الـ workflow نفسه. وتقدر تشغّله يدويًا: Actions ← Android app ← Run workflow.
- **بناء التطبيق (`apk`)**، بصلاحية قراءة بس:
  1. `npm ci` في `app/`، ثم `npx cap sync android`: ينسخ `public/` داخل التطبيق كما هي.
  2. **مفتاح التوقيع:** يفك السر `ANDROID_KEYSTORE_B64` لملف مؤقت، ويتأكد إنه ينفتح بكلمة السر والاسم. إذا السر ناقص أو غلط، البناء يوقف برسالة واضحة. ويطبع أطوال وبصمة قصيرة بس، ما فيها شي سري.
  3. `./gradlew assembleRelease`: يبني APK موقّع.
- **النشر (`publish`)**، بصلاحية كتابة بس هنا:
  - يرفع `alaabna.apk` لإصدار **`app-latest`** في صفحة Releases.
  - الملف يتبدّل بمكانه (يرفع نسخة باسم ثاني، ثم يحذف القديمة ويعيد التسمية)، فرابط التحميل ما ينكسر أبد. وإذا فشل الرفع تبقى النسخة القديمة.
  - وسم `app-latest` يتحرك على نفس الـ commit.
- **الرابط** اللي يفتحه تنبيه التحديث: صفحة إصدار `app-latest` (مكتوب في `tools/bump.sh`).

### أسرار التوقيع

أربعة أسرار في GitHub (Settings ← Secrets and variables ← Actions):

| السر | وش فيه |
|---|---|
| `ANDROID_KEYSTORE_B64` | ملف المفتاح كامل بصيغة base64 |
| `ANDROID_KEYSTORE_PASSWORD` | كلمة سر الملف |
| `ANDROID_KEY_ALIAS` | اسم المفتاح داخل الملف |
| `ANDROID_KEY_PASSWORD` | كلمة سر المفتاح |

- **المفتاح الحالي من نوع EC.**
- كل نسخة لازم تنوقّع بنفس المفتاح عشان تنثبّت فوق اللي قبلها. لو ضاع المفتاح، ما تقدر تحدّث التطبيق المثبّت عند الناس.
- خطوات إنشاء مفتاح وإضافة الأسرار في [SETUP.md](../SETUP.md).

> **ممنوع منعًا باتًا:** رفع أي مفتاح أو ملف `.jks`/`.keystore` أو كلمة سر أو قيمة سر للمستودع، أو كتابتها في التوثيق أو في سجل البناء. المستودع عام. الملفات `*.jks` و`*.keystore` متجاهلة في `.gitignore`.

## نسخة خاصة من المستودع

إذا أحد سوّى نسخة (fork) ويبي تطبيقه الخاص، يغيّر عنوان الخادم ورابط التحديث واسم التطبيق ويسوي مفتاح توقيع خاص فيه. الخطوات في [SETUP.md](../SETUP.md).

## بعد النشر

- **افتح الموقع:** المفروض يطلع الرقم الجديد في `version.json`.
- **جرّب غرفة أونلاين بجوالين.**
- **في التطبيق** المفروض يطلع «فيه تحديث للتطبيق»، وتنزّل `alaabna.apk` من `app-latest` وتثبّته فوق القديم.
