# ألعابنا

ألعاب ويب من لاعبين اثنين إلى 8 لاعبين، على نفس الجهاز أو أونلاين برمز غرفة.

## الألعاب
1. إكس أو: الشبكة تكبر مع عدد اللاعبين (3×3 للاثنين، وتوصل 8×8)، ومن 3 لاعبين يصير الفوز بأربعة ورا بعض
2. نقاط ومربعات: الشبكة تكبر مع العدد، والفائز صاحب أكثر مربعات
3. السلم والثعبان: حتى 8 قطع على اللوحة
4. حرب الألوان: اللوحة تكبر مع العدد، واللي يخسر كل خاناته يطلع
5. معركة السفن: كل لاعب يختار مين يضرب، واللي تغرق كل سفنه يطلع
6. خمّن الشخص: تسأل عن شخصية أي لاعب، التخمين الصح يطلّعه والغلط يطلّعك

## التشغيل
الملف الوحيد هو `index.html`، كل شيء داخله.

اللعب أونلاين يعتمد على خاصية الغرف في صفحات Claude، فيشتغل لما تُفتح الصفحة من claude.ai. خارج claude.ai يشتغل وضع «على نفس الجهاز» فقط.
