# ألعابنا

ألعاب ويب للاعبين اثنين، على نفس الجهاز أو أونلاين برمز غرفة.

## الألعاب
1. إكس أو
2. نقاط ومربعات
3. السلم والثعبان
4. حرب الألوان
5. معركة السفن
6. خمّن الشخص

## التشغيل
الملف الوحيد هو `index.html`، كل شيء داخله.

اللعب أونلاين يعتمد على خاصية الغرف في صفحات Claude، فيشتغل لما تُفتح الصفحة من claude.ai. خارج claude.ai يشتغل وضع «على نفس الجهاز» فقط.
