# ألعابنا

26 لعبة ويب، كل لعبة تقبل من لاعبين اثنين إلى 8 لاعبين، على نفس الجهاز أو أونلاين برمز غرفة. القوانين وحجم اللوحة يتغيرون حسب عدد اللاعبين.

## الألعاب
**ألعاب لوحة:** إكس أو، نقاط ومربعات، السلم والثعبان، حرب الألوان، معركة السفن، أربعة في صف، خمسة على التوالي

**ورق وزهر:** لعبة الذاكرة، أعلى أو أقل، بلاك جاك 21، ألوان وأرقام، دومينو، بنقو، زهر المخاطرة

**ذكاء وتخمين:** خمّن الشخص، الكنز المدفون، حقل الألغام، خمّن الكلمة، خمّن الرقم، أعواد الكبريت، كسر الشفرة، لا تقول 31

**مسابقات وتحدي:** حجرة ورقة مقص، مسابقة المعلومات، سباق الحساب، عواصم الدول

## بنية المشروع
1. `index.html` الصفحة
2. `css/style.css` التصميم
3. `js/core.js` المحرك: اللاعبين والأدوار والمزامنة والشاشات
4. `js/transport-firebase.js` الاتصال أونلاين عبر Firebase مع تسجيل دخول وقائمة مسموحين
5. `js/firebase-config.js` إعدادات Firebase (فاضية حتى تربط مشروعك)
6. `js/games/` ملفات الألعاب، كل لعبة كائن فيه: `init` و`render` و`click`، والألعاب المتزامنة فيها `resolve`
7. `database.rules.json` قواعد حماية قاعدة البيانات

## طريقة عمل المزامنة
كل لاعب ينشر نسخته من حالة اللعبة مع رقم تسلسلي، وكل جهاز ياخذ النسخة الأحدث. الأسرار (سفن، شخصية سرية، اختيار في جولة متزامنة) تكون في الجزء الخاص بكل لاعب.
الفكرة مأخوذة من أسلوب boardgame.io: اللعبة دوال بسيطة تغيّر الحالة، والمحرك يتكفل بالباقي.
